# CivicPulse Static Assets & Design Resources

This directory contains shared static assets, vectors, and design resources for CivicPulse:

- `images/`: Reusable high-resolution images, brand banners, and architectural schematics.
- `icons/`: SVG icons, municipal agency badges, and vector glyphs.

Note: Client-bundled assets consumed directly by Vite at runtime are located in `frontend/public/` and `frontend/src/`.
